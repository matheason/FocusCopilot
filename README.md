# FocusCopilot

An intelligent browser extension that tracks time spent across tabs, analyzes productivity vs. slacking trends, and provides AI-powered guidance to keep you focused.

## ✨ Features

- **⏱️ Smart Time Tracking**: Automatically log time spent on different websites and active tabs.
- **📊 Productivity Analytics**: Calculate weekly focus/slacking indices with visual charts.
- **🤖 AI Insights**: Get personalized advice, humorous nudges, and summary reviews powered by AI models.
- **🚀 Lazy One-Click Action**: Quick redirects or prompts to get back on track when slacking off.

## 🛠️ Tech Stack

- **Manifest**: V3
- **Browsers**: Microsoft Edge, Google Chrome, and other Chromium-based browsers
- **Frontend**: HTML / CSS / JavaScript
